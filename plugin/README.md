# 我的设备中心 · DSH 接入插件

将当前 DSH Desktop 或 Web 实例接入自己部署的设备中心，在手机、平板的浏览器中使用同一份会话。

安装后在左侧栏底部点击 `⇄` → 设置，填写中心 HTTPS 地址、电脑名称和一次性配对码。配对码在中心网页的「设备」菜单生成。首次安装如未出现按钮，完全退出并重新打开 DSH。

配对后电脑主动连接中心，不需要固定家庭公网 IP 或路由器端口映射。电脑离线时不能执行任务；中心不会把任务转移到其他电脑。

本插件与预测／改写插件完全独立。不发送模型请求，不修改提示词或会话记录。

适配 DSH 0.2.1-rc.3。设备凭据保存在 `~/.dsh-center/host.json`，可用环境变量 `DSH_CENTER_CONFIG` 指定独立路径。不要让两个运行实例共用同一份凭据。

只有本机可操作配对界面；远程隧道不允许调用配对接口。可在中心撤销设备。

安全边界：HTTPS/WSS 两段加密，中心能看到转发内容，请只使用可信中心。不是端到端加密，也不提供操作系统远程桌面。
